# AI 연결 설정

사용자가 AI API 연결 작업 도중 여러 모델을 비교할 수 있도록 설정 페이지의 키 입력 방식으로 변경 요청했다. 이번 변경은 제공사·키·모델 설정과 연결 확인까지 구현한다. 분석·자동 주문 엔진은 이 설정을 사용하는 후속 기능이며 설정 저장 자체로 실행하지 않는다.

- OpenAI·Anthropic·Gemini 각각 키와 모델 선택을 보존하고 활성 제공사를 선택한다.
- 키는 비밀번호 입력란에서 받고 백엔드에서 Windows 사용자 범위 DPAPI로 암호화한다. GET·검증 실패 응답에 키를 반환하지 않는다. 브라우저 저장소에 키를 쓰지 않는다.
- 저장/삭제/연결 확인은 상태 버전을 검사하며 연결 확인 도중 키가 바뀌면 오래된 결과를 버린다.
- 공식 HTTPS 모델 목록 GET만 연결 확인에 사용한다. 모델 목록은 인증/조회 가능 확인이며 생성 권한·잔액·분석 적합성 검증은 아니다. 모델 ID 직접 입력도 허용한다.
- 입력 키가 비어 있으면 기존 저장 키를 유지한다. 삭제는 제공사별 명시적 버튼으로 수행한다. OpenAI 키는 서버의 Api_Key.txt에서 명시적으로 가져올 수 있다.
- 원본 키 파일은 변경하지 않는다. Windows 계정이 바뀌어 암호화 자료를 열 수 없으면 오류로 처리하고 평문 저장으로 대체하지 않는다.
- 독립 임시 저장소에서 암호화·재시작·상태 변경·응답 비노출과 UI 동작을 검증하고 EXE에 반영한다.

## 검증 완료

- AI 관련 20개를 포함한 전체 Python 테스트 123개 통과, JavaScript 요청 식별자 테스트 및 ESLint 통과.
- 임시 설정에서 키 저장 후 입력란 비움, 모델 목록 선택/직접 입력, 제공사별 보존, Claude 키 삭제 시 OpenAI 키 유지 확인.
- 실제 OpenAI 키로 공식 모델 목록만 조회하여 79개 후보와 GPT-5.6 Terra 접근 목록 포함을 확인. 생성 호출은 하지 않음.
- Windows 사용자 계정에서 암호화한 설정을 EXE 사용자 폴더에 처음 적용하고, 1.8.0 Portable에서 정상 복호화·모델 선택·키 비노출 응답 확인. 기존 실전 모드와 매매 정지 상태 유지.
