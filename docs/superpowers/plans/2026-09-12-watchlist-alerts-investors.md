# 관심종목·가격 알림·수급 구현 계획

**Goal:** 국내 관심종목과 일회성 가격 알림, 날짜별 개인·외국인·기관 수급을 기존 다크 테마 앱에 추가한다.

**Architecture:** 별도 SQLite에 관심종목·알림을 저장한다. 조회 워커는 화면 열람 중인 관심종목과 대기 알림만 기존 나무 클라이언트로 순차 조회한다. 수급은 currentInvestor를 정규화하고 별도 화면 컴포넌트에서 기준일과 함께 표시한다. 알림은 주문 엔진을 호출하지 않는다.

**Tech Stack:** FastAPI, SQLite, React, Electron, 기존 NAMUH PLUG 클라이언트.

**Spec:** 사용자가 승인한 관심종목 + 가격 알림 + 수급 표시. 국내주식만, 기존 다크 테마, 추가 외부 데이터 없음.

## 제약
- 실제 주문을 전송하는 검증 금지. 주문 화면 이동만 연결한다.
- 앱·서버 실행 중 감시하며 종료 중 가격 변화는 추적하지 않는다. API 순차 조회 간격과 조회 시각을 표시한다.
- 정규장 평일 09:00~15:30에 알림 조건을 검사한다. 휴장일 별도 판별 불가 및 시세 지연 가능성을 안내한다.
- 영문 포함 6자리 코드 지원. 잘못된/빈 시세는 알림 조건에 사용하지 않는다.
- 조건 해제·관심종목 삭제 도중 늦게 도착한 시세가 알림을 발생시키지 않도록 저장 상태 재확인.
- 수급 누락값을 0으로 대체하지 않는다. 샘플의 *z10 필드는 의미가 확인되지 않으면 임의 단위 변환하지 않는다.
